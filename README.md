# VK Social Commerce Prototyping Environment

Внутренняя среда для продуктовых дизайнеров Соц-коммерции VK. Проект предназначен для быстрой сборки мобильных экранов, связанных состояний и кликабельных React-прототипов по текстовому запросу.

## Назначение

Целевые возможности среды:

- быстрая сборка простых мобильных экранов;
- генерация связанных состояний и экранов;
- создание React-прототипов, работающих в браузере;
- использование подтверждённых компонентов и токенов дизайн-системы VK;
- последующее редактирование результата через текстовые запросы;
- critique и final QA по правилам Соц-коммерции.

## Текущий статус

Сейчас в проекте:

- определена продуктовая область;
- настроены адаптеры Codex и Claude;
- существует архитектура progressive-disclosure skills;
- зафиксированы roadmap и актуальный статус проекта.

Пока не готовы:

- подтверждённые VK foundations;
- токены, типографика, иконки и кодовые компоненты VK;
- продуктовые паттерны Соц-коммерции;
- `vk-commerce-*` skills;
- генерация финальных VK-прототипов;
- целевой showcase и deployment.

Репозиторий не следует считать готовым VK UI-kit. Соответствие дизайн-системе VK можно заявлять только после подключения и проверки официальных источников.

## Для кого

- продуктовые дизайнеры Соц-коммерции VK;
- в дальнейшем — другие участники продуктовой команды, если среда окажется для них полезной.

## Работа с агентами

Точки входа:

- [`AGENTS.md`](AGENTS.md) — правила для Codex;
- [`CLAUDE.md`](CLAUDE.md) — правила для Claude Code;
- [`.agents/README.md`](.agents/README.md) — конвенция архитектуры skills.

Codex читает `.agents/skills/` напрямую. Claude использует `.claude/skills` как symlink на `../.agents/skills`.

Подтверждёнными источниками для продуктовых решений являются только материалы VK, явно добавленные и отмеченные в репозитории. При отсутствии токенов, компонентов или паттернов агент должен сообщить о нехватке данных и перечислить допущения.

## Целевой workflow

`brief → prototype → critique → final QA`

Это целевой workflow. Соответствующие `vk-commerce-*` capability skills ещё не созданы и не являются работающей частью проекта.

## Локальный запуск showcase

Текущий showcase является технической частью репозитория и пока не подтверждает готовность VK UI-kit. Его `package.json` и `package-lock.json` находятся в `apps/showcase`, поэтому команды выполняются из этой папки:

```bash
cd apps/showcase
npm ci
npm run dev
```

Проверка production-сборки:

```bash
cd apps/showcase
npm run build
```

Предпросмотр собранной версии:

```bash
cd apps/showcase
npm run preview
```

## Структура репозитория

- `.agents/` — каноническая архитектура skills;
- `.claude/` — доступ Claude к общей директории skills;
- `apps/showcase/` — текущий демонстрационный runtime;
- `docs/` — продуктовая и техническая документация;
- `AGENTS.md` и `CLAUDE.md` — адаптеры агентов.
