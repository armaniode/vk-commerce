# .examples/

Эта папка — **архив реальных задач**, которые автор делал в этом репозитории с LLM-агентом. Не правила, не документация — пример того, как выглядит рабочий цикл.

## Что внутри

| Файл | О чём |
|---|---|
| [`tasks-todo-example.md`](tasks-todo-example.md) | План одной конкретной задачи (WEB-модалка для лендинга): цель, чек-лист, фазы, критерии готовности |

## Зачем это для нового пользователя

Если ты только что склонировал репозиторий и не уверен, как подойти к большой задаче с LLM-агентом — посмотри сюда. Это **демонстрация привычки**: до того, как просить агента «сделай X», автор формулирует `todo.md` с чек-листом, фазами, явными критериями готовности. Агент потом возвращается к этому файлу как к источнику истины.

Базовые принципы рабочего цикла:
1. Сложная задача → план в `tasks/todo.md` (не сразу в чат).
2. Каждая правка от пользователя → строка в `tasks/lessons.md`.
3. Перед сдачей — пройтись по rules/critique.md (6-мерное ревью).

Эти принципы прописаны в [CLAUDE.md](../CLAUDE.md) — агент будет им следовать автоматически.

## Использовать как шаблон

Скопируй `tasks-todo-example.md` в `tasks/todo.md` своего форка и адаптируй под свою задачу. Структура подходит под любую UI-сборку: hero, модалка, лендинг, экран приложения.
