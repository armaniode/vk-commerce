# Статус миграции VK Social Commerce

Статус после этапа 3: переходные адаптеры агентов.

| Слой | Статус | Комментарий |
|---|---|---|
| Product scope | Готов | Зафиксирован в `docs/product-scope.md` |
| Migration map | Готов | Зафиксирован в `docs/migration-map.md` |
| Agent adapters | Переходный слой | Codex и Claude знают контекст VK Social Commerce, но VK skills ещё не созданы |
| VK design-system sources | Не начато | Нет подтверждённых токенов, типографики и Figma sources |
| VK tokens | Не начато | Carnica tokens не использовать |
| VK icons | Не начато | Нужен отдельный источник |
| VK components | Не начато | Компоненты Carnica не являются заменой |
| VK skills | Не начато | Целевой префикс `vk-commerce-` |
| React prototype generation | Не начато | Будет реализовано после базовых foundations и компонентов |
| Social Commerce patterns | Не начато | Нужны реальные продуктовые сценарии |
| Critique and final QA | Не начато | Пока существуют только legacy Carnica workflows |
| Showcase migration | Не начато | Текущий showcase остаётся legacy |
| Legacy cleanup | Не начато | Удаление только после появления VK-замены |
| Vercel deployment | Отключён | Legacy workflow отключён до настройки нового проекта |

## Что агент может делать сейчас

- анализировать архитектуру репозитория;
- документировать миграцию;
- подготавливать структуру будущих skills;
- проводить аудит входных материалов VK;
- работать с Git и документацией.

## Что агент пока не должен делать

- заявлять соответствие дизайн-системе VK;
- собирать финальные VK-экраны из Carnica;
- переносить Beeline branding;
- придумывать отсутствующие токены и компоненты как официальные;
- удалять legacy до появления замены.

## Следующий этап

Сбор и аудит реальных источников дизайн-системы VK:

- токены;
- типографика;
- иконки;
- компоненты;
- Figma-библиотеки;
- продуктовые паттерны Соц-коммерции.
