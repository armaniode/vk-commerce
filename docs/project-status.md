# Статус проекта VK Social Commerce

Актуальный статус VK Social Commerce Prototyping Environment.

## Готово

| Слой | Состояние | Подтверждение |
|---|---|---|
| Product scope | Готов | [`docs/product-scope.md`](product-scope.md) |
| Implementation roadmap | Готов | [`docs/implementation-roadmap.md`](implementation-roadmap.md) |
| Agent adapters | Готовы для текущего этапа | `AGENTS.md` и `CLAUDE.md` описывают контекст, ограничения и workflow |
| Skills architecture | Готова как архитектура | `.agents/README.md` фиксирует progressive disclosure и общую конвенцию |

## В работе

| Слой | Состояние | Следующее действие |
|---|---|---|
| VK design-system sources | Подготовка к аудиту | Получить доступы, владельцев и список Figma-библиотек |
| Figma setup | Правила подключения определены | Проверить реальные источники по `docs/figma-setup.md` |

## Не начато

| Слой | Комментарий |
|---|---|
| VK foundations | Нет подтверждённых токенов, типографики и правил темизации |
| VK icons | Нужен подтверждённый источник и правила экспорта |
| VK components | Нужны source of truth, variants, states и паспорта |
| `vk-commerce-*` skills | Создаются только после подтверждения соответствующих источников |
| React prototype generation | Зависит от foundations и базовых компонентов |
| Social Commerce patterns | Нужны реальные продуктовые сценарии и владельцы |
| Critique and final QA | Нужны критерии, основанные на подтверждённых правилах VK |
| Showcase | Нужны готовые данные, компоненты и формат каталога |
| Deployment | Настраивается после готовности целевого showcase |

## Что агент может делать сейчас

- анализировать архитектуру репозитория;
- работать с Git и документацией;
- уточнять продуктовые требования;
- подготавливать структуру будущих skills;
- проводить аудит входных материалов VK;
- фиксировать источники, блокеры и допущения.

## Ограничения текущего этапа

- Нельзя заявлять соответствие дизайн-системе VK без подтверждённых источников.
- Нельзя придумывать официальные токены, компоненты, иконки и patterns.
- Нельзя считать наличие архитектуры skills доказательством готовности продуктовых skills.
- Нельзя считать текущий showcase целевым каталогом VK Social Commerce.

## Следующий этап

Аудит реальных источников дизайн-системы VK:

- Figma-библиотеки;
- токены;
- типографика;
- иконки;
- компоненты;
- продуктовые паттерны Соц-коммерции;
- права доступа и владельцы источников.
