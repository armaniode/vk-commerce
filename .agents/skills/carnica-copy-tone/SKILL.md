# Carnica Copy & Tone of Voice

Этот skill хранит voice-of-brand Beeline: tone of voice (близкий, человеческий, спокойный), список запрещённых generic-AI фраз и канцелярита, правила lowercase UI с исключениями, правила пунктуации (без точки в конце короткой подписи / кнопки), типовые шаблоны микрокопии (loading / empty / error / success / confirmation / snackbar / CTA) и тональные вариации по контексту (транзакционный / ошибка / onboarding / маркетинг / юридический).

## Когда обращаться

- Пишешь UI-текст: заголовок секции, placeholder, лейбл, кнопку, snackbar, tooltip
- Копирайтишь лендинг, промо-баннер, hero, секцию продукта
- Формулируешь error messages, empty states, confirmation dialogs, success notifications
- Проверяешь тон после автогенерации (LLM часто выдаёт generic-AI канцелярит)
- Выбираешь между несколькими формулировками — нужны 3 варианта с разными углами
- Сверяешь lowercase, пунктуацию и «билайн со строчной» перед финальной сдачей
- Сомневаешься, как назвать действие: «отправить заявку прямо сейчас» или «отправить»

### Lowercase правила UI

Весь UI-текст — **строчными**. Заголовки экранов, кнопки, лейблы полей, тэги, пункты меню, начало предложений внутри абзаца после точки.

С большой буквы — только эти категории:

| Категория | Примеры |
|---|---|
| Имена людей | Илья, Анна, Дмитрий |
| География | Москва, Санкт-Петербург, ул. Тверская |
| Бренды кроме билайн | МТС, Apple, iPhone, Samsung, Steam, Xbox |
| Аббревиатуры-протоколы | eSIM, SMS, QR, SIM, 5G, HD, ID, URL, API |
| Названия тарифов в кавычках | «Вверх!», «Всё онлайн», «Чёрный титан» |
| Email и номера | user@example.com, +7 999 123 45 67 |

⚠ **Слово «билайн» — всегда строчными**, даже в начале предложения. Это часть бренд-идентичности. Логотип `BeelineBall` — отдельный графический элемент, на него правило не распространяется.

⚠ **Сокращения единиц измерения (гб, мб, мбит, ггц, мин, тб)** — это типографика, owner `carnica-typography`. Здесь только напоминание: всегда строчными.

Запрещено:
- CAPS LOCK (`ИТОГ`, `ОФОРМИТЬ`, `ВЫЙТИ`)
- CSS `text-transform: uppercase`
- Ручная капитализация слов («Заголовок», «Итог»)
- `letter-spacing` для имитации CAPS-стиля

### Пунктуация в UI

| Правило | Пример ✅ | Пример ❌ |
|---|---|---|
| Точка в конце короткой подписи / кнопки / заголовка секции / FAQ-вопроса — **не ставится** | «итог заказа», «оплатить» | «итог заказа.», «оплатить.» |
| Точка внутри абзаца — разделитель предложений | «обычно в течение 8 дней. точная дата придёт в SMS» | — |
| После точки — следующее предложение со строчной | «...точная дата. она придёт в SMS» | «...точная дата. Она придёт в SMS» |
| Восклицательные в UI — **не используем** | «готово», «сохранено» | «готово!», «сохранено!» |
| Восклицательные допустимы только в названиях тарифов в кавычках | «Вверх!» | — |
| Кавычки — «ёлочки» | «Чёрный титан» | "Чёрный титан", «Чёрный титан» |
| Длинное тире «—» с пробелами вокруг | «связь — это просто» | «связь - это просто» |
| Короткое тире «–» без пробелов между числами для диапазона | «5–10 дней» | «5-10 дней», «5 — 10 дней» |
| «и/или» — не использовать | «и» или «или» | «и/или» |
| Неразрывный пробел между числом и единицей | «7&nbsp;гб», «1 199&nbsp;₽» | «7 гб» с обычным пробелом |
| Неразрывный пробел после коротких предлогов в long-form RU | «в&nbsp;Москве», «и&nbsp;тогда» | — |

Детали неразрывных пробелов и единиц — `carnica-typography`.

### Tone по контексту

Базовая TOV единая (человеческая, lowercase). Оттенки меняются по сценарию.

| Контекст | Тон | Пример |
|---|---|---|
| Транзакционный (платёж, покупка) | спокойный, конкретный | «оплачено. чек на почте» |
| Обнаружение проблемы (ошибка, лимит) | без обвинения, с предложением | «закончились гб. подключим ещё?» |
| Onboarding | приветливый, без пафоса | «давайте настроим ваш номер» |
| Маркетинг / промо | без давления, конкретно | «безлимитный интернет за 590 ₽/мес» |
| Юридическое / условия | максимально просто | «можно отказаться в течение 14 дней без объяснения причин» |

## Decision rules

1. **TOV check вслух** — прочитай готовый текст вслух. Если звучит как пресс-релиз / справочник / корпоративный сайт — переписывай. Цель: «как друг объяснил». Это главный фильтр, важнее любых таблиц.

2. **Lowercase везде, кроме явных исключений** — имена / география / бренды (кроме билайн) / аббревиатуры (eSIM, SMS, QR) / названия тарифов в кавычках / email / номера. Всё остальное — строчными, включая начало предложений внутри абзаца после точки.

3. **Точка в конце короткой строки — убирай** — последнее предложение подписи / кнопки / заголовка секции / FAQ-вопроса / лейбла. Внутри абзаца сохраняй как разделитель между предложениями.

4. **Слово «билайн» — строчное всегда** — даже в начале предложения, если контекст это позволяет. Это бренд-правило Beeline, не общерусское. Логотип `BeelineBall` — графика, на него не распространяется.

5. **3 варианта формулировки для важного текста** — для любого CTA, заголовка лендинга, hero-копи предлагай 3 варианта с разными углами (рациональный / эмоциональный / минимальный). Не выбирай за пользователя. См. memory: `feedback_offer_three_text_variants`.

6. **Конкретика вместо абстракции — P0** — «оптимизировать» → «ускорить», «инновационный» → удалить, «бесшовный опыт» → «открывается за секунду», «функционал» → «функция». Generic-AI слова из таблицы Quick reference — это P0 anti-slop нарушение (см. `carnica-anti-slop`).

7. **Микрокопия — imperative + объект** — «продолжить», «отменить», «удалить», «оплатить 1 199 ₽» (глагол + объект). Не «Нажмите для продолжения», не «отправить заявку прямо сейчас».

8. **Tone адаптируй по контексту, базу — не меняй** — error мягче (без обвинения, с предложением «попробуем ещё»), success короче («готово»), confirmation прямой («оплатить 1 199 ₽?»), marketing бодрее (но без давления и !!! ), юридическое максимально простыми словами. Базовая TOV (lowercase + человеческий) остаётся.

9. **CTA-кнопки конкретные, с действием / суммой** — «оплатить 1 199 ₽» лучше «перейти к оплате», «подключить» лучше «активировать новый тариф», «закрыть» / «понятно» лучше «ОК». В кнопке — глагол + объект, без обобщений.

10. **Без восклицательных в UI** — кроме названий тарифов в кавычках («Вверх!»). В snackbar success предпочитай точку или ничего: «готово» лучше «готово!».

11. **Lorem ipsum / «текст-заполнитель» — никогда** — даже в макете на ранней стадии. Используй реальный или приближённый по смыслу контент. Lorem ipsum в продакшен-копии — P0 нарушение и сигнал ленивого автогена.
